Available Super Protocol profiles

The GPU column shows the type and number requested by the flavor. Nova assigns physical cards when a VM is launched. An unavailable GPU profile is not replaced automatically.

Nova extra specs, native PCI requests and Placement state accounting are generated automatically. Profile creation does not reserve resources or require currently free GPUs. At launch the entire VM must fit on one host. The technical flavor name is generated from resources; the display name is stored in its description. Existing profiles are reused without renaming or editing them. To change resources, create another profile; this never resizes a running VM.
