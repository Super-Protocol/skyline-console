Create Swarm cluster

Choose an approved provider configuration and resources for every node. Use Auto placement or select a compute host for each node (administrators). An explicit host must fit the entire VM; no fallback to another host is used. The seed must pass signature and CA readiness before any join starts. No SSH or VM restart is used.

New provider template

The directory must contain swarm/config.yaml. Files are uploaded over HTTPS and stored privately in Barbican. The template is an independent snapshot; GitHub tokens, PowerDNS API keys and other recognized secrets are masked in previews.
