General settings

Administrator-only settings for this OpenStack deployment.

Debug images

Allow registration and new launches of debug images on all currently enrolled computes. TDX / SEV-SNP mode, resources and scheduling state are not changed. Running VMs are not stopped or restarted.

Debug builds may expose diagnostic access. Use only in a trusted test environment; this setting does not open network ports. Debug cannot be forbidden while a non-CC debug-only compute is enrolled.

Swarm UI publication

Configure once before creating public Swarm clusters. Swarm retains DNS credentials and manages DNS records and certificates. This service only publishes HTTP/TLS-SNI routes and verifies public HTTPS. One ingress and one writer are supported; this is not HA.

Public addresses are independent of the local bind address. Configure an external VIP/L4 load balancer separately; preserve HTTP Host and TLS SNI. Disabling new publication does not remove existing routes.
