Add Swarm node

Add one join node to an existing cluster. Bootstrap and current nodes stay running.

Free capacity is checked before submission. The check does not reserve resources; Nova makes the final placement decision.

Auto lets Nova select a host. An explicit host must fit the entire VM; there is no fallback to another host. A requested GPU is never silently replaced with CPU-only.
